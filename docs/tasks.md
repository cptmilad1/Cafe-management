# وضعیت کار: دیتابیس کافه

- بر اساس `docs/ai.txt` یک اسکلت PostgreSQL برای مدیریت کافه اضافه شد؛ موجودیت‌ها به‌دلیل نبود نیازمندی جزئی در متن، مدل پایه هستند.
- اتصال مشترک `pg.Pool` در `database/base/pool.js` قرار دارد و تنظیمات محیطی را از `.env` می‌خواند.
- فایل‌های مستقل در `database/schema/` جدول‌های کاربران، دسته‌بندی‌ها، محصولات، میزها، سفارش‌ها، آیتم‌های سفارش، پرداخت‌ها و ایندکس‌ها را می‌سازند.
- `database/schema/run.js` فایل‌های SQL را به ترتیب شماره و در یک تراکنش اجرا می‌کند. اجرای آن با `npm run db:schema` انجام می‌شود.
- وابستگی‌های ریشه `pg` و `dotenv` نصب شده‌اند؛ متغیرهای نمونه در `.env.example` هستند. مقادیر واقعی اتصال باید در `.env` تنظیم شوند.
- بررسی syntax جاوااسکریپت و نصب وابستگی‌ها موفق بود. اعمال schema هنوز تأیید نشده: اجرای runner با `ECONNREFUSED` روی `localhost:5432` شکست خورد، چون PostgreSQL در دسترس نبود.
- گام بعد: PostgreSQL را اجرا کنید، دیتابیس `cafe_management` را بسازید، تنظیمات `PGHOST`، `PGPORT`، `PGDATABASE`، `PGUSER` و `PGPASSWORD` را در `.env` قرار دهید و `npm run db:schema` را دوباره اجرا کنید.
